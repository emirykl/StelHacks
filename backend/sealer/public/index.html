StelHacks sealer

Holds sealed scorecards and ballots during judging, and publishes one digest committing to all of them when the window closes. It decides nothing: the root is a function of the entries it holds.

POST /scorecardtake a signed, time-locked card
POST /ballotthe same, for the crowd
POST /sealpublish the root on chain
GET /rootthe root it would publish
GET /proofthe inclusion proof for one leaf
